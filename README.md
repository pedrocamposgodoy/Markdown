# PDF → Markdown

Convierte documentos PDF a Markdown para reducir el gasto de tokens al analizar con IA.

## Ejecutar en local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Desplegar en Streamlit Cloud (gratis)

1. Sube esta carpeta a GitHub.
2. Entra en https://share.streamlit.io
3. Conecta el repo, selecciona `app.py` y despliega.

La URL pública resultante se puede compartir directamente sin instalar nada.

## Archivos

- `app.py` — aplicación principal
- `requirements.txt` — dependencias
- `.streamlit/config.toml` — tema oscuro
- `README.md` — este archivo
